# AI Chat UI

A single-file, professional AI chat interface (HTML + CSS + JavaScript, no backend).

**Live:** https://melleeyyy.github.io/chat-ui/

## Features
- Dark / Light theme
- Multiple chat sessions (sidebar)
- File upload (image, PDF, TXT)
- Streaming AI response (typewriter effect)
- Voice input & text-to-speech
- Think & Search modes
- Markdown support (code, tables, lists)
- Copy / Edit / Regenerate / Delete messages
- Export chat as Markdown
- Mock AI responses (no backend needed)
- Keyboard shortcuts
- Mobile responsive
